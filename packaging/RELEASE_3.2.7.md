# SteamCommandGen v3.2.7

## English

The window opens within the usable area of a 720p screen and adapts its controls when resized, without window scrollbars. Game artwork keeps its aspect ratio and long game titles no longer force the window to grow. Command generation and button behavior are unchanged.

**Ubuntu/Debian:** install the `.deb` package. **SteamOS/Steam Deck and other x86_64 Linux systems:** use the AppImage, or extract the ZIP and run `./install.sh` without `sudo`.

The ZIP contains only the application, its required assets, installer, uninstaller, and license; it does not contain documentation or development files.

---

## Español

La ventana se abre ajustada al área útil de una pantalla de 720p y adapta sus controles al redimensionarse, sin barras de desplazamiento. Las carátulas se ajustan sin recortes y los títulos largos de juegos ya no fuerzan el ancho de la ventana. No se modifica la generación de comandos ni el comportamiento de los botones.

**Ubuntu/Debian:** instala el paquete `.deb`. **SteamOS/Steam Deck y otros Linux x86_64:** usa el AppImage o extrae el ZIP y ejecuta `./install.sh` sin `sudo`.

El ZIP incluye exclusivamente los archivos del programa, sus recursos, el instalador, desinstalador y la licencia; no incluye documentación ni archivos de desarrollo.
