# SteamCommandGen

SteamCommandGen es una herramienta gráfica diseñada para generar y gestionar opciones de lanzamiento de Steam utilizando **Gamescope**.
Permite crear configuraciones avanzadas de resolución, nitidez, escalado y parámetros de rendimiento para juegos de Steam de forma sencilla y visual.

![SteamCommandGen Screenshot](assets/screenshots/main.png)

---

## ✨ Características

- Generación automática de comandos Gamescope
- Interfaz gráfica con **PyQt6**
- Ajustes de nitidez (0–5)
- Resoluciones personalizadas
- Escalados
- Integración con Steam (LaunchOptions)
- Exportación de comandos
- Disponible como **AppImage**, **paquete .deb** y **script instalador**

---

# 📦 Instalación

SteamCommandGen puede instalarse de tres maneras distintas, dependiendo de la distribución y preferencias del usuario.

---

## 🟩 Opción 1: Instalar el paquete `.deb` 

Descarga el `.deb` desde la sección **Releases** y ejecuta:

sudo apt install ./steamcommandgen_1.0.deb

## 🟩 Opción 2: Instalar el paquete con Script 

Descargar el `.zip` desde la sección **Releases** y ejecuta:

chmod +x install.sh
./install.sh

## 🟩 Opción 3: Usar el AppImage

Descarga el `.AppImage` desde la sección **Releases** y ejecuta:

chmod +x SteamCommandGen-x86_64.AppImage
./SteamCommandGen-x86_64.AppImage
